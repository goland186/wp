# Готовый продукт миграции: caranddriver.ru → WordPress + Motors

Пакет подготовлен по 8-этапному плану миграции. Продукт готов к развёртыванию на сервере.

## Быстрый старт (2 действия) — СМ. SHORT-DEPLOY.md

Все файлы уже в репозитории: ядро WordPress (`wordpress/`), дамп БД (`database/old_dump.sql`), тема Motors (`new-theme/Motors/`), этот пакет (дочерняя тема + скрипты + wp-cli.phar).

```bash
git clone https://github.com/goland186/wp.git && cd wp/package/caranddriver-motors-migration
cp config.env.sample config.env && nano config.env   # 5 значений
bash run-migration.sh config.env                      # действие 1: сайт целиком
bash run-migration.sh config.env uploads              # действие 2: папка uploads + финал
```

## Что внутри

1. **Дочерняя тема `motors-child/`** — главный артефакт. Переносит функционал и внешний вид старой темы ColorMag 1.3.5 в Motors 5.6.95 без правки родительской темы:
   - **header.php / footer.php / sidebar-footer.php — реплика шапки и подвала ColorMag**: лого (custom_logo 661 из старой БД), дата, бегущая строка новостей, меню (location `primary`), иконки home/поиск/случайный пост, 4 колонки виджетов подвала, строка копирайта;
   - `assets/colormag/` — оригинальные CSS/JS ColorMag 1.3.5 (style.css, fontawesome, bxslider, newsTicker, sticky, fitvids, magnific-popup) — вид старого сайта 1:1;
   - главная страница сохраняет старую раскладку: слайдер избранных постов → блок у слайдера → верхняя секция → две средние колонки → нижняя секция → текст страницы «Автомобильный портал»;
   - области виджетов зарегистрированы со **старыми идентификаторами** (`colormag_front_page_slider_area` и др.), а классы виджетов — со **старыми именами**: настройки из старой БД (баннеры 300x250/728x90, слайдер, вертикальные списки постов) подхватываются автоматически, порядок блоков сохраняется 1:1;
   - хелперы ColorMag (цвета рубрик, плашки категорий, адаптивные YouTube-встраивания, шапка/подвал) — в `inc/cd-legacy-functions.php`;
   - полифиллы `stm_is_car_dealer()` и др. (функции bundled-плагинов Motors) — без них страницы записей падают с фаталом «Call to undefined function».

2. **`plugins/` — zip-ы плагинов в репозитории** (интернет на сервере не нужен): `wordpress-seo.zip` (Yoast SEO — SEO-мета старых постов подхватится из `_yoast_wpseo_*`), `cyr3lat.zip` (Cyr-to-Lat — тот же плагин, что был на старом сайте), `captcha.zip` (BestWebSoft Captcha). Устанавливаются и активируются скриптом с обязательной проверкой.

3. **Серверные скрипты `server-scripts/`** — весь конвейер развёртывания от бэкапа до 301-редиректов (см. DEPLOY.md): перенос настроек темы `setup-child-mods.php`, сверка контента, сверка медиатеки, карта 301. Все скрипты прошли проверку синтаксиса (`php -l`, `bash -n`) и прогон на реальном дампе.

4. **Реестры ссылок на картинки `server-scripts/registries/`** — страховка медиатеки, извлечены из старого дампа БД:
   - `registry_attachments.csv` — 8121 вложений: путь в uploads + канонический URL + все размерные варианты;
   - `registry_urls_in_content.csv` — 9310 ссылок на картинки в контенте 1210 постов;
   - `registry_external_images.csv` — 2397 внешних изображений (остаются как есть);
   - `uploads_paths_expected.txt` + `uploads_expected_stats.json` — 67 769 ожидаемых файлов по папкам 2010–2026;
   - `image_url_summary.json` — сводка по всем источникам изображений.

5. **Baseline для приёмки**: `baseline.json` (16 метрик старого сайта), `baseline-post-urls.tsv` (1198 URL постов) — скрипты 05/07 сверяют новую версию с ними автоматически.

6. **`migration-report.md`** — таблица сравнения старое/новое (заполняется скриптом 05 на сервере) и нерешённые вопросы.

## Проверено end-to-end (локальный прогон на WP 7.1.4 + дамп старой БД)

- Motors 5.6.95 распаковывается, motors-child активируется; активная тема подтверждается `wp theme list`.
- wordpress-seo, cyr3lat, captcha устанавливаются и активируются из локальных zip.
- Шапка рендерится: `#masthead`, лого (вложение 661), дата + бегущая строка, 9 пунктов «Main Menu» в `primary`.
- Подвал рендерится: `#colophon`, строка копирайта.
- Страница записи (шаблон Motors), рубрика, страница, поиск — HTTP 200, шапка/подвал на месте, без фаталов.
- Сверка контента: **все 16 метрик OK** (1198 постов, 8121 вложение, 21425 комментариев, 123 рубрики, 1159 меток, 5 пользователей, 6 меню, 15 элементов меню, ЧПУ, главная, Yoast 19/85, 5/5 областей главной).

## Критерии приёмки (из техзадания)

| Критерий | Как проверяется |
|---|---|
| Все страницы и посты старого сайта присутствуют | `05-verify-content.php`: 1198 постов, 2 страницы, счётчики 1:1 |
| Порядок блоков главной сохранён | motors-child front-page.php + те же области виджетов |
| Функционал (слайдер, баннеры, списки постов) работает | те же классы виджетов с теми же настройками из БД |
| URL, слаги, SEO-мета не изменились | ЧПУ `/ГГГГ/ММ/ДД/слаг/`; Yoast-мета в мета постов; `07-redirects.php` сверяет 1198 URL |
| Все ссылки на картинки рабочие | пути uploads не менялись; `06-verify-images.php` сверяет 8121+67769 файлов с реестром |
| Демо-контент Motors не затёр контент | демо-импорт запрещён (DEPLOY.md, ЭТАП 5) |
