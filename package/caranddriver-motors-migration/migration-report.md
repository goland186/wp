## 3. Сохранение контента и структуры (ЭТАПЫ 4–5 плана)

- **Данные**: весь контент переносится импортом родного дампа — правки контента не выполнялись.
- **Блоки**: конструктор — Gutenberg + виджетная система ColorMag. Виджеты главной перенесены в дочернюю тему с теми же идентификаторами областей и классов → порядок и настройки блоков сохраняются из БД без ручной сборки.
- **Функционал**: слайдер избранных постов, highlighted-блок, горизонтальные/вертикальные списки постов, рекламные баннеры (300x250, 728x90, 125x125) — портированы из ColorMag 1.3.5 в motors-child (GPL-совместимо). YouTube-встраивания (221) — ядро WP + обёртка .fitvids-video.
- **Motors**: демо-контент НЕ импортируется; родительская тема не правится; вся кастомизация в motors-child.

## 4. SEO и URL (ЭТАП 8 плана)

- ЧПУ и домен не меняются → для 1198 постов 301 не требуется (проверка `07-redirects.php` по baseline).
- SEO-мета Yoast хранится в постмете (`_yoast_wpseo_title`, `_yoast_wpseo_metadesc`, фокус-ключевые слова) → после установки актуального Yoast подхватывается автоматически.
- Фиды плагинов Турбо/Dzen закрыты Яндексом → 301 на `/feed/` (генерируется скриптом 07).
- Обязательные действия после включения: sitemap_index.xml в Яндекс.Вебмастер и Google Search Console.

## 6. Гарантии сохранности ссылок на картинки

1. Пути `uploads/ГГГГ/ММ/имя` не меняются ни на одном этапе (проверено по дампу: `uploads_use_yearmonth_folders=1`, все 8121 `_wp_attached_file` внутри uploads).
2. Реестр `registry_attachments.csv` — точный эталон (ID вложения → путь → URL → все миниатюры).
3. Скрипт `06-verify-images.php` на сервере сверяет **каждый** файл и **каждую** внутреннюю ссылку из контента; недостающие — списком в `missing-uploads.csv`.
4. Загрузка `uploads/` выполняется последним шагом (по регламенту заказчика) — до этого шага битые картинки ожидаемы и не влияют на контент/URL.
